# Intent Analysis — 意图分析

> 用户说的 ≠ 用户要的。先理解意图，再拆需求。

## 分析模板

当用户提出请求时，AI 应先输出：

```markdown
## Intent Analysis
- 用户说了：<原文>
- 真实意图：<一句话>
- 场景：<这个功能在什么场景下使用？>
- 成功标准：<什么算"做好了"？>
- 非目标：<明确不在这次范围内的事情>
```

## 示例

用户："增加好友系统"

```
Intent Analysis:
- 用户说了：增加好友系统
- 真实意图：提升玩家社交互动，增强留存
- 场景：玩家想一起组队时先加好友
- 成功标准：可发送/接受/删除好友请求，显示在线状态
- 非目标：不包含公会系统，不包含语音聊天
```

## 规则

- 意图分析**必须**在写代码前完成
- 简单任务（单文件、明确输入输出）可跳过
